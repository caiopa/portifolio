### Como executar

Para rodar o projeto localmente e visualizar:

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:

   ```bash
   npm start
   ```

3. O aplicativo abrirá em `http://localhost:3000`
